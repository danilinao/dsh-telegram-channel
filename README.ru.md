# dsh-telegram-channel — русская версия

Telegram-**пульт для DeepSeek Harness**: телефон подключается к уже идущей
сессии на компьютере и работает с ней **той же дорогой**, что и Web-интерфейс —
один диалог, две видимые стороны (подход Codex).

Это форк: интерфейс переведён на русский, архивные сессии скрыты из меню,
на кнопке показано наименование сессии. Что именно изменено и как
пересобирать — в [FORK-RU.md](FORK-RU.md). Оригинал —
[hi-wenw/dsh-telegram-channel](https://github.com/hi-wenw/dsh-telegram-channel).

## Как это устроено

Компьютер — источник истины. Плагин живёт внутри процесса `dsh web`, ничего не
запускает параллельно и не «изобретает» второй агент: сообщение из телефона
уходит в **ту же** сессию, и вы видите его и на компьютере. То, что видно в
Web, видно и в телефоне.

## Установка

```bash
dsh plugin --profile web add link:/home/alexey/dsh-plugins/dsh-telegram-channel
systemctl restart dsh
```

Конфигурация — строка `- id: dsh-telegram-channel` в
`~/.dsh/profiles/web/cordis.patch.yml`:

```yaml
- id: dsh-telegram-channel
  name: dsh-telegram-channel
  config:
    token: "<токен от @BotFather>"
    allowedUserIds: [<ваш числовой id>]
```

| Ключ | Смысл |
|---|---|
| `token` / `DSH_TELEGRAM_TOKEN` | токен бота |
| `allowedUserIds` / `DSH_TELEGRAM_ALLOWED_USER_IDS` | белый список; пусто — не отвечает никому |
| `allowAllUsers` | `true` только для отладки |
| `maxMessageLength` | по умолчанию 4096 |
| `pollingTimeoutSec` | по умолчанию 30 |
| `rendering` | `html` (по умолчанию, любой клиент) или `rich` |

## Как пользоваться

1. `/start` — приветствие и краткая инструкция
2. `/sessions` — **рабочая область → сессия → привязать** (архивные и пустые
   скрыты; ▷ значит, что сессия поднимется при привязке)
3. Дальше просто пишите — сообщение идёт в ту же сессию, что открыта в Web

| Команда | Что делает |
|---|---|
| `/sessions` | список рабочих областей → сессий → привязка |
| `/last` | последний вопрос-ответ привязанной сессии |
| `/model` | сменить модель (со следующего хода) |
| `/status` | состояние: модель, глубина размышлений, контекст, TTFT, токены |
| `/compact` | сжать историю сессии (когда она свободна) |
| `/rich` | `on` — rich-рендер, `off` — HTML (для этого чата) |
| `/stop` | прервать текущий ход |
| `/mission` | список задач и прогресс |
| `/new` | новый диалог в текущей области и сразу привязка |
| `/unbind` | отвязать телефон (сессия на компьютере остаётся) |
| `/cancel` | закрыть ответы/подтверждения в Telegram (в Web они остаются) |
| `/help` | помощь |

Поддерживаются текст и картинки (png/jpeg/webp/gif, в том числе с подписью;
альбомы склеиваются в одно сообщение). Голос, видео и прочие файлы — через Web.

## Безопасность

Бот отвечает только id из белого списка. Токен утёк — `/revoke` у `@BotFather`
и новый токен в `cordis.patch.yml`. Файл конфигурации — режим `600`.

## Сеть

`api.telegram.org` на этом хосте доступен только через тоннель AmneziaWG
(Telegram DC маршрутизируются через `awg0`). Без тоннеля бот молчит —
`sudo tunnel-route status` покажет, ушли ли маршруты `149.154.160.0/20`.
